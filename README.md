### 🔍 Tools that make the invisible visible

Software does a lot you never see: an installer quietly edits your shell profile, a dependency
drags in half a framework, a `save` sends an email. Each of these tools surfaces one of those,
in a different ecosystem.

| | Project | What it shows you | |
| :-: | :-- | :-- | :-- |
| 🔮 | **[soothsay](https://github.com/rijuld/soothsay)** | What a `curl \| sh` install script will do *before* it runs: profile edits, `sudo`, startup items, nested downloads, credential access. Also a Claude Code hook that stops AI agents from running installers nobody has read. | ![Rust](https://img.shields.io/badge/Rust-000?style=flat-square&logo=rust) [![crates.io](https://img.shields.io/crates/v/soothsay?style=flat-square&color=000)](https://crates.io/crates/soothsay) |
| ⚖️ | **[heft](https://github.com/rijuld/heft)** | How much of each Go dependency your program actually reaches, and whether copying the 12 lines you use beats importing the module. | ![Go](https://img.shields.io/badge/Go-000?style=flat-square&logo=go) |
| 🧾 | **[sidefx](https://github.com/rijuld/sidefx)** | A receipt for everything a block of Rails code did: rows written, callbacks, jobs, mail, HTTP, cache. Assert on it in CI. | ![Rails](https://img.shields.io/badge/Rails-000?style=flat-square&logo=rubyonrails&logoColor=CC0000) |
| 🎯 | **[rebuild_budget](https://github.com/rijuld/rebuild_budget)** | Exactly which Flutter widgets an interaction rebuilds, with a budget that fails CI when someone's `setState` starts rebuilding half the screen. | ![Flutter](https://img.shields.io/badge/Flutter-000?style=flat-square&logo=flutter&logoColor=02569B) |

### 🧪 Research

- **[GameWorldScore](https://github.com/rijuld/gameworldscore)**: RL finetuning of the Oasis Minecraft world model with GRPO and a ground-truth-free, five-part reward. No reference videos; the model learns from scored rollouts.
- **[DO-ELECT](https://github.com/rijuld/dual-objective-elect)**: a dual-objective extension of ELECT (ICCV 2025) for instruction-guided image editing with diffusion models.
- **[BareNet](https://github.com/rijuld/cuda-tensor-autograd)**: a minimal CUDA tensor library with Python autograd, co-built from scratch as a team project.
- **[Peri-Urban Hyderabad change detection](https://github.com/rijuld/Peri-Urban-Hyderabad-Change-Detection-Dataset)**: a satellite dataset pairing three years of surface reflectance with seven air-pollution bands.

### 🤖 AI agents & apps

- **[Pivt](https://github.com/rijuld/pivt)**: a logistics war room where IBM watsonx Orchestrate agents detect shipment exceptions, reroute trucks, price alternatives against SLA penalties, and draft the notices.
- **[agent-surf](https://github.com/rijuld/agent-surf)**: one-click internet access for AI agents, picking and health-checking the most reliable backend for each platform.
- **[Anchor](https://github.com/rijuld/agentic-mesh-mental-health-app)**: a BPD recovery companion for patients, allies and clinicians (React Native, Express, multi-agent AI).
- **[yuka](https://github.com/rijuld/yuka)**: point your phone at a food label and get a nutrition score, with on-device OCR and Gemini.
